# Vết Ấn Dưới Rễ Cây

MVP Godot 4 cho ba khu vực mở đầu của game action RPG top-down:

1. Rừng Sương Mù: thức tỉnh, học di chuyển, nhận lại thanh kiếm.
2. Con Đường Rừng: combo, né, kỹ năng và miniboss Hươu Sừng Rễ.
3. Thị Trấn Gió Than: lửa trại, đổi class, nâng chỉ số, lò rèn, shop và quest board.

## Điều khiển

- Di chuyển: WASD, phím mũi tên hoặc D-pad.
- Đánh thường: chuột trái, J hoặc nút X.
- Né: Space, K hoặc nút A.
- Kỹ năng 1: Q, L hoặc nút Y.
- Tương tác: E hoặc nút B.
- Tạm dừng: Esc.

Project dùng placeholder hình học dựng trực tiếp trong Godot vì Assets.md chưa cung cấp asset nguồn. Mở project.godot bằng Godot 4.3 trở lên và chạy main scene.
